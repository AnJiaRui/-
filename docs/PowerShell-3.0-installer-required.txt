OFFLINE INSTALLER PLACEHOLDER

This folder is reserved for the official Microsoft PowerShell 3.0 offline installer.
Do not rename a random file to .exe. Copy the genuine installer here before moving the project to an offline Windows 7 computer.

Recommended file names:
- Windows6.1-KB2506143-x64.msu  (Windows 7 64-bit)
- Windows6.1-KB2506143-x86.msu  (Windows 7 32-bit)

PowerShell 3.0 cannot be generated by this project. It must come from an official Microsoft installation package prepared on a computer with network access or from approved installation media.

The current computer already has PowerShell 5.1, so no installation is needed here.
