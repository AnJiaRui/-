# JinShan 离线 OCR 使用说明

## 一、功能简介

JinShan 是一个完全本地运行的图片文字识别工具：

- 图片不会上传到网络。
- 支持 JPG、PNG、WEBP 图片。
- 支持简体中文、英文、中英混合识别。
- 识别结果可以复制或保存为 TXT。
- 支持将识别文字以模拟键盘输入的方式输入到其他软件。

## 二、目录说明

```text
JinShan/
├─ JinShan.html                 OCR 页面入口
├─ auto-type.bat                自动识别并自动输入
├─ type-result.bat              手动读取 TXT 并模拟输入
├─ install-powershell3.bat      检查并安装 WMF/PowerShell
├─ css/                         页面样式
├─ js/                          页面功能脚本
├─ tesseract/                   本地 OCR 引擎和语言包
├─ scripts/                     PowerShell 功能脚本
├─ offline-installers/          离线安装包
└─ docs/                        说明文档
```

## 三、自动模式

推荐使用自动模式：

1. 双击根目录的 `auto-type.bat`。
2. 等待 OCR 页面打开。
3. 将图片拖入黑色 CMD 风格窗口，或点击 `Choose Image`。
4. 等待识别完成。
5. 识别结果会自动保存到根目录的 `recognition-result.txt`。
6. 自动输入程序启动，并显示 5 秒倒计时。
7. 倒计时期间切换到目标软件的输入框。
8. 倒计时结束后，文字会以每分钟约 150 个字符的速度输入。

输入过程中：

- 按一次 `Tab`：暂停输入。
- 再按一次 `Tab`：继续输入。

## 四、手动模式

如果不使用自动监听：

1. 直接打开 `JinShan.html`。
2. 拖入图片并等待识别完成。
3. 点击 `Save TXT` 保存识别结果。
4. 将文件保存为根目录的 `recognition-result.txt`。
5. 双击 `type-result.bat`。

也可以在命令行中输入其他文本文件：

```bat
type-result.bat "D:\text\result.txt"
```

## 五、离线 OCR 文件

`tesseract` 文件夹必须包含：

```text
tesseract/
├─ tesseract.min.js
├─ worker.min.js
├─ tesseract-core.wasm.js
├─ tesseract-core.wasm
└─ lang-data/
   ├─ chi_sim.traineddata.gz
   └─ eng.traineddata.gz
```

`.traineddata.gz` 文件不要解压。缺少任意核心文件都可能导致识别失败。

## 六、Win7 离线安装

Win7 建议使用 Win7 SP1，并准备 WMF 5.1 离线安装包。正确的 Win7 x64 文件夹示例：

```text
offline-installers/
└─ Win7AndW2K8R2-KB3191566-x64/
   ├─ Install-WMF5.1.ps1
   └─ Win7AndW2K8R2-KB3191566-x64.msu
```

如果是 32 位系统，应准备 `Win7-KB3191566-x86.msu`。

双击根目录的 `install-powershell3.bat` 后，程序会：

1. 检查 PowerShell 主版本。
2. 如果已经是 PowerShell 3.0 或更高版本，则跳过安装。
3. 自动判断系统是 x86 还是 x64。
4. 递归扫描 `offline-installers` 文件夹。
5. 优先调用微软提供的 `Install-WMF5.1.ps1`。
6. 找不到官方脚本时，再直接调用对应的 `.msu` 文件。

WMF 5.1 通常要求 Windows 7 SP1 和 .NET Framework 4.5 或更高版本。

## 七、浏览器要求

- Win10：建议使用 Edge、Chrome 或 Firefox。
- Win7：建议使用支持 WebAssembly 的 Chrome 或 Firefox。
- 不建议使用 IE。
- 旧版浏览器如果不支持 WebAssembly、Web Worker 或 Promise，无法运行当前 Tesseract.js OCR 引擎。
- 页面会在启动时显示兼容性警告。

## 八、自动模式注意事项

- `auto-type.bat` 会启动本机 `127.0.0.1:8765` 监听器，只用于当前电脑内部通信。
- 第一次运行可能被 Windows 防火墙询问，请只允许本地专用网络访问。
- 如提示权限不足，可以右键 `auto-type.bat`，选择“以管理员身份运行”。
- 自动输入开始前有 5 秒倒计时，请提前点击目标软件的输入框。
- 模拟输入期间不要切换到其他窗口，否则文字会输入到当前获得焦点的窗口。
- 普通键盘按键不会被系统级屏蔽；`Tab` 专门用于暂停和继续。

## 九、常见问题

### 页面显示找不到 OCR 引擎

检查 `tesseract` 文件夹是否与 `JinShan.html` 在同一项目根目录，并确认文件没有被杀毒软件隔离。

### 识别一直加载

第一次识别需要加载 WASM 和语言模型，中文模型文件较大，需要等待一段时间。相同语言的后续识别会复用已加载模型。

### 自动输入没有启动

确认是通过 `auto-type.bat` 启动，而不是直接双击 `JinShan.html`。自动模式需要本地监听器。

### 安装脚本找不到 WMF 文件

确认 `.msu` 文件放在 `offline-installers` 或它的子文件夹中，并且文件名包含：

```text
KB3191566
```

不要使用 Win8.1 或 Windows Server 2012 的安装包安装 Win7。

## 十、安全提醒

- 只使用微软官方来源的 WMF、PowerShell 和 OCR 文件。
- 不要把未知来源的 `.ps1`、`.bat` 或 `.msu` 文件放入项目后直接运行。
- `ExecutionPolicy Bypass` 只用于当前启动命令，不会修改系统的永久执行策略。
- 离线使用时，建议先用杀毒软件扫描所有安装包和脚本。
- 模拟键盘输入具有实际操作效果，运行前请确认目标窗口和输入内容正确。
